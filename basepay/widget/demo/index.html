Anvil Supply Co.

A demo storefront wired to the local BasePay stack. Nothing here is real money.

Pay it from anvil

With the local stack running, send the exact quoted amount from a funded anvil account:

cd basepay
npm run dev:pay --workspace server -- <amount-usdc> <merchant-address>

Then watch the widget move pending → confirming → paid.

The Webflow embed

<script src="https://pay.example.com/widget/widget.js"
        data-merchant="demo"
        data-amount-usd="45.00"
        data-order-ref="ORDER-1001"
        data-target="#basepay"></script>
